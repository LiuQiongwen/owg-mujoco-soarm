\begin{abstract}
Learned grasp reranking promises to improve open-world manipulation, yet
practitioners lack principled guidance on when such methods reliably help
or harm. We present LGGSN, a lightweight pairwise-trained MLP that reranks
GR-ConvNet candidates using geometric and query-conditioned features within
a language-conditioned pipeline. Training with Bayesian Personalised Ranking
(BPR) loss and augmenting the base feature set with episode-relative context
and object query embeddings improves offline ranking accuracy from 0.447 to
0.750. Through a systematic paired evaluation over 175 trials (25 seeds $\times$ 7
objects, MuJoCo/SO-ARM101), we establish a geometric predictability framework:
objects with low flat fraction (\texttt{flat\_frac} $< 0.1$) yield consistent
reranking gains (PowerDrill $+4$, MustardBottle $+2$), while geometrically
degenerate objects (\texttt{flat\_frac} $> 0.4$) cause feature saturation that
nullifies ranking signal. Spearman correlation between \texttt{flat\_frac} and
reranking outcome reaches $\rho = -0.96$ on PyBullet ($p < 0.01$) and
$\rho \approx -0.5$ on MuJoCo, where thin objects exhibit an execution
floor effect rather than a ranking failure,
enabling deployment-time prediction of reranker utility without trial execution. Our work provides the
first systematic characterization of geometry-dependent reranking behavior in
open-world grasping, and establishes concrete requirements for successor methods
targeting degenerate object categories.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Language-conditioned robot manipulation requires not only identifying
\emph{which} object to grasp but also selecting a grasp pose that will
physically succeed.
Vision-based candidate generators such as GR-ConvNet~\cite{kumra2020grconvnet}
produce a ranked list of candidate grasps, but their quality estimates are
computed independently per image patch, without considering the full
geometry of the episode or the semantic properties of the target object.
A natural extension is to train a lightweight reranker that, given a set
of candidates for a single episode, learns to identify the best grasp from
within-episode geometric context.

Prior work on grasp quality estimation largely operates offline on fixed
object sets with known geometry~\cite{mahler2017dexnet,fang2020graspnet1b}.
In open-world settings, where object identity is specified at runtime via
natural language, the reranker must generalise across a diverse object
distribution without access to CAD models or object-specific supervision.
This introduces a fundamental challenge: the features that discriminate
good from bad grasps depend heavily on object geometry, yet the reranker
must be trained on a shared feature space.

We design and evaluate LGGSN within the OWG (Open-World Grasping)
pipeline~\cite{owg2024}, which uses a Vision-Language Model (VLM) grounder
to localise objects and GR-ConvNet to generate grasp candidates.
Our contributions are:
\begin{enumerate}
  \item \textbf{A pairwise BPR training procedure} for grasp reranking from
    live robot data, which avoids the within-episode label degeneracy that
    causes BCE training to collapse.
  \item \textbf{Two episode-relative context features}
    (\texttt{dist\_to\_centroid}, \texttt{z\_rel}) that address feature
    collapse in top-down scenarios and improve offline pair accuracy by
    49\,\%.
  \item \textbf{A paired empirical evaluation} over 25 seeds $\times$
    7 objects (175 trials) that reveals the net task effect of reranking is near zero,
    driven by object-dependent failure modes predictable from geometric
    statistics.
  \item \textbf{A diagnostic framework} correlating per-object geometric
    properties (flat fraction, height spread, yaw spread) with reranking
    benefit, explaining both where the method helps and where it harms.
\end{enumerate}

This paper reports a predominantly negative result: the system does not
reliably improve overall task success.
Its value lies in a reproducible geometric diagnosis of \emph{why}
geometry-only reranking fails for specific object categories, and in the
concrete design requirements this diagnosis exposes for future systems.

\section{Related Work}
\label{sec:related}

\subsection{Grasp Quality Estimation}

GraspNet-1Billion~\cite{fang2020graspnet1b} and related methods learn grasp
quality predictors from large annotated datasets of 3-D point clouds, using
object-centric representations.
Dex-Net~\cite{mahler2017dexnet} formulates grasp quality as a function of
contact geometry and friction, training on simulated perturbation outcomes.
AnyGrasp~\cite{fang2023anygrasp} extends this paradigm with a graspness
representation that generalises across unseen objects in cluttered scenes,
still assuming access to dense point-cloud geometry.
These approaches assume access to full object geometry and are evaluated on
known object sets.
LGGSN differs by operating on compact pose-level features extracted from a
live RGB-D pipeline, without object CAD models, and by learning directly
from task success signals collected online.

\subsection{Pairwise and Listwise Learning to Rank}

Bayesian Personalised Ranking (BPR)~\cite{rendle2009bpr} was originally
proposed for collaborative filtering and has since been applied across
recommendation and information retrieval.
Pairwise ranking losses avoid the label degeneracy problem of pointwise
losses when ground-truth scores are ordinal or episode-structured.
In grasping, \cite{mousavian2019graspnet6dof} applies listwise ranking to
offline grasp datasets.
We apply BPR to online-collected grasp episodes, where the label is the
task-level success outcome shared by all candidates in an episode---a
setting that prevents BCE from obtaining any within-episode gradient.

\subsection{Learning from Robot Interaction}

DexGraspNet~2.0~\cite{fang2024dexgraspnet2} and
RoboAgent~\cite{bharadhwaj2024roboagent} demonstrate learning grasp policies
directly from robot experience.
Our setting is lower data (605 episodes, 7 objects) and targets a plug-in
reranker rather than an end-to-end policy.
The closest prior work in this regime is \cite{morrison2020grconvnet}, which
trains a grasp success predictor from live trials; we extend this direction
to the pairwise setting and study the failure modes that emerge at the level
of individual object categories.
Concurrent work on learning-based grasp selection from interaction data
includes~\cite{ze2024gnfactor,vuong2024grasp}, which focus on task-level
success in cluttered scenes but do not analyse per-object geometric failure modes.

\subsection{Language-Conditioned and Open-World Grasping}

Language-conditioned manipulation has advanced rapidly with large vision-language
models (VLMs).
CLIPort~\cite{shridhar2022cliport} uses CLIP features for semantic pick-and-place
without object-specific models.
RT-2~\cite{brohan2023rt2} and OpenVLA~\cite{kim2024openvla} co-fine-tune VLMs
on robot action data, achieving broad language-following but at the cost of
high compute and limited grasp-pose precision.
GraspGPT~\cite{tang2023graspgpt} grounds natural-language task descriptions
to grasp affordances, focusing on \emph{which} grasp to choose rather than
improving a candidate generator's quality estimates.
SpatialVLM~\cite{chen2024spatialvlm} enhances spatial reasoning in VLMs for
manipulation, but operates at the policy rather than the reranker level.
OWG~\cite{owg2024} and its Stage~4 reranker provide the pipeline we augment;
LGGSN is the only component using learned geometric reasoning beyond the
VLM grounder and GR-ConvNet generator.
To our knowledge, no prior work provides a systematic failure analysis of
learned reranking across diverse object geometries in an open-world setting.

\section{Method}
\label{sec:method}

\subsection{System Overview}

The OWG pipeline has two stages relevant to this work:
\begin{itemize}
  \item \textbf{Stage~3 (baseline):} VLM grounder localises the target
    object; GR-ConvNet generates $N$ grasp candidates; the top-ranked
    candidate by GR-ConvNet score is executed.
  \item \textbf{Stage~4 (proposed):} Same candidate generation; LGGSN
    reranks the $N$ candidates; the top-ranked candidate by LGGSN score
    is executed.
\end{itemize}
LGGSN is a lightweight MLP trained offline on live-collected episode data
and loaded at inference time.

\subsection{Feature Representation}

Each grasp candidate is represented by an 18-dimensional feature vector.

\noindent\textbf{Base features (12-dim):}
grasp position $(x,y,z)$; orientation $(\phi, \theta, \psi)$ in world-frame
RPY; gripper opening \texttt{width}; GR-ConvNet quality \texttt{score};
pre-grasp vertical offset \texttt{dz}; post-grasp lift \texttt{dz\_lift};
collision-avoidance flag \texttt{need\_dz}; estimated object height at
grasp point $H$.

\noindent\textbf{Episode-relative context features (2-dim, v2):}
\begin{itemize}
  \item \texttt{dist\_to\_centroid}: L2 distance from the candidate's
    $(x,y)$ to the episode centroid $(\bar{x},\bar{y})$.
    Encodes how central or peripheral the approach is.
  \item \texttt{z\_rel}: min-max normalised height within the episode,
    $(z - z_{\min})/(z_{\max} - z_{\min} + \varepsilon)$.
    Encodes relative vertical position within the episode's height range.
\end{itemize}

\noindent\textbf{Object query embedding (4-dim, v5d):}
A learned embedding $\mathbf{e}_q \in \mathbb{R}^4$, implemented as
$\mathtt{nn.Embedding}(7,\,4)$, is appended to the 14-dimensional geometric
features and trained jointly with the MLP\@.
The class index $q \in \{$banana, can, pear, mustard, drill, cracker,
cylinder$\}$ is derived from the VLM grounding output.
The combined input
$\mathbf{x} = [\mathbf{x}_\mathrm{geom};\, \mathbf{e}_q] \in \mathbb{R}^{18}$
allows LGGSN to adapt feature weighting per object class.
At inference, an unknown class uses the mean over all seven embeddings.

\noindent\textbf{Motivation.}
In typical top-down grasping, five of the twelve base features---$x$, $y$,
$\phi$, $\theta$, and \texttt{width}---are nearly constant across all
candidates in a single episode (the gripper approaches from directly above
at a fixed overhead position).
This leaves only 7 effectively informative geometric dimensions for
within-episode ranking; the query embedding adds 4 object-conditional dimensions.
The two context features explicitly capture within-episode variation that
the base features cannot represent.

\subsection{LGGSN Architecture}

LGGSN is a 2-layer MLP:
\begin{equation}
  f(\mathbf{x}) = \mathbf{W}_2\,\mathrm{ReLU}(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1) + b_2
  \label{eq:mlp}
\end{equation}
where $\mathbf{x} \in \mathbb{R}^{18}$,
$\mathbf{W}_1 \in \mathbb{R}^{40 \times 18}$,
$\mathbf{W}_2 \in \mathbb{R}^{1 \times 40}$.
Total parameters: 829 (including $7 \times 4 = 28$ for the query embedding table).
At inference time, $\sigma(f(\mathbf{x}))$ is used as the quality score.

\subsection{BPR Training}

\noindent\textbf{Dataset construction.}
Episodes are collected by running the OWG pipeline in MuJoCo simulation with the SO-ARM101 manipulator.
Each episode produces $N$ grasp candidates for a given (object, scene) pair
and receives a binary label based on whether the executed grasp succeeded.
Grounding-failed episodes (VLM API timeout or HTTP error) are identified by
cross-referencing the batch log and excluded from training, as their
negative labels reflect network failures rather than geometric failures.

\noindent\textbf{Pairwise label.}
For a pair of episodes $(p, n)$ with the same query object where $p$
succeeded and $n$ failed, each candidate in $p$ is treated as a
\emph{positive} and each candidate in $n$ as a \emph{negative}.
This cross-episode pairwise signal is the only supervision available:
within a single episode all candidates share the same label, so no
within-episode gradient exists under a pointwise loss.

\noindent\textbf{Loss.}
The BPR loss for a (positive, negative) candidate pair is:
\begin{equation}
  \mathcal{L}_{\mathrm{BPR}}
  = -\log\,\sigma\!\bigl(f(\mathbf{x}_{+}) - f(\mathbf{x}_{-})\bigr)
  \label{eq:bpr}
\end{equation}

\noindent\textbf{Training details.}
Adam optimiser, $\text{lr}=10^{-3}$, batch size 32, 30 epochs, 80/20
episode-level train/val split.

\subsection{Geometry-Conditioned Gate (GC-LGGSN)}

As a negative-result variant, we trained a GC-LGGSN in which a 3-dim
episode context $\mathbf{z} = [\text{flat\_frac},\,\sigma_H,\,\sigma_\psi]$
gates the 14-dim feature vector via a learned sigmoid mask ($+302$ parameters,
trained jointly under \cref{eq:bpr}).
Results are in \cref{sec:gcresult}.

\section{Experiments}
\label{sec:experiments}

\subsection{Evaluation Protocol}

All experiments use a \emph{paired} evaluation: for each (seed, object)
pair, Stage~3 and Stage~4 are run on the same MuJoCo/SO-ARM101 scene.
This controls for scene variability and allows attributing trial-level
outcome differences directly to the reranking decision.

\noindent\textbf{Metric.}
\begin{equation}
  \text{net} =
  \underbrace{|\{i : \text{S4}_i{=}1 \!\land\! \text{S3}_i{=}0\}|}_{\text{impr.}}
  -
  \underbrace{|\{i : \text{S3}_i{=}1 \!\land\! \text{S4}_i{=}0\}|}_{\text{regr.}}
  \label{eq:net}
\end{equation}

\noindent\textbf{Scale.}
Primary evaluation: 25 seeds $\times$ 7 objects $= 175$ paired trials.
Ablation studies: 10 seeds $\times$ 6 objects $= 60$ trials.

\noindent\textbf{Objects.}
Banana, CrackerBox, MustardBottle, Pear, PowerDrill, Scissors,
TomatoSoupCan---seven YCB objects spanning flat/thin, cylindrical,
box-like, round, and asymmetric-tool geometries.

\subsection{Training Data}

The candidate log \texttt{lggsn\_live\_candidates.jsonl} contains 3,026
candidate records from live episode collection covering all seven objects.
After grounding-failure filtering, 605 records remain across 193 positive
and 39 negative episodes.
Pairs are formed as the Cartesian product of all (positive episode,
negative episode) pairs per query object.
The positive-to-negative episode ratio is approximately 5:1 (193 vs.\ 39),
meaning each negative episode participates in many more pairs than each
positive; this imbalance is inherent to the online collection setting
(successes are more common than failures once the pipeline is functional)
and is not re-weighted during training.

\subsection{Main Result}

\Cref{tab:main} reports the Stage~3 vs.\ Stage~4 comparison on
MuJoCo/SO-ARM101.
The deployed checkpoint is v5d (18-dim features with query embedding,
val pair\_acc 0.750; see \cref{tab:ablation} row~E).
The per-object breakdown in \cref{tab:main} uses v2 (14-dim) data to include
all seven objects; v5d gains on the 5-object training subset are reported in
\cref{tab:ablation}.
The aggregate net improvement under v2 is $+1$: PowerDrill improves
consistently ($+4$), while CrackerBox ($-2$), MustardBottle ($-1$), and
Pear ($-1$) regress.
Scissors registers zero success on both stages, a floor effect that
provides no reranking signal.
Stage~3 achieves 66.8\,\% (117/175) and Stage~4 achieves 67.4\,\%
(118/175).
\Cref{fig:barplot} visualises the per-object breakdown.
Cross-platform validation against PyBullet/Panda results appears in

\noindent\textbf{Key finding.}
An offline accuracy improvement from 0.579 (12-dim) to 0.664 (14-dim)
does not translate to a net task improvement: the features most
informative for offline ranking---particularly $H$ and
\texttt{z\_rel}---are precisely those that saturate or mislead on
flat/thin objects (see \cref{sec:failure}).

\noindent\textbf{Statistical caveat.}
At $N = 10$ seeds $\times$ 6 objects $= 60$ trials per condition,
the 95\,\% bootstrap CI on net improvement spans approximately $\pm 5$--$6$
trials.
The net differences between conditions (e.g., Cond~B at $+7$ vs.\ Cond~D at
$-1$) are directionally consistent with the 25-seed primary result but lie
within this noise band.
The ablation results should therefore be interpreted as \emph{indicative} of
feature contributions rather than conclusive evidence; replication at
$N \geq 50$ would be required to resolve individual condition differences
reliably.

\subsection{Gating Strategies for Failure Mitigation}

\noindent\textbf{Flat-object gate ($\sigma_H < 0.005$).}
Reranking is skipped when the within-episode standard deviation of $H$
falls below a threshold.
The gate fires on 53--62\,\% of CrackerBox and MustardBottle episodes
(blocking valid reranking) but on only 10\,\% of Scissors episodes;
per-object results: CrackerBox $+3$, PowerDrill $-3$, Scissors $-3$.
Net $= -2$ overall, worse than the ungated baseline.

\noindent\textbf{Object-conditional whitelist (CrackerBox + MustardBottle).}
The whitelist eliminates the Scissors regression ($0$ vs.\ $-4$) but
simultaneously degrades CrackerBox ($-3$ from $+4$) and MustardBottle
($-3$ from $+2$).
Net $= -1$.

\subsection{GC-LGGSN: Geometry-Conditioned Feature Gating}
\label{sec:gcresult}
Evaluated on CrackerBox and Scissors (25 seeds each), GC-LGGSN achieves
net $= 0$ overall (CrackerBox $+1$, Scissors $-1$), partially correcting
the Scissors regression ($-4 \to -1$) but degrading CrackerBox ($+4 \to +1$).
The episode context $\mathbf{z}$ is insufficiently discriminative to
simultaneously benefit both objects; whether a larger gate resolves this
on the full 7-object set remains open.

\subsection{Per-Object Failure Analysis}
\label{sec:failure}

\Cref{tab:geom} pairs per-object geometric statistics (from MuJoCo
episodes) with PyBullet/Panda net improvement; \cref{fig:scatter}
plots the scatter.
We use PyBullet net here because the MuJoCo Scissors floor effect
(0/25 baseline) masks the regression: PyBullet's non-zero baseline
(20/25) exposes it as $-4$.
Spearman correlation of flat\_frac with S4 net (PyBullet):
$\rho = -0.96$ ($p < 0.01$).
On the MuJoCo platform, Scissors exhibits a floor effect (0/25 both
stages) rather than a regression, reducing the correlation to
$\rho \approx -0.5$; the directional relationship holds but is
attenuated by the execution constraint.
Spearman correlation of $\sigma_{H,\text{within}}$ with S4 net
(PyBullet): $\rho = +0.81$ ($p < 0.05$).
These are the two strongest predictors of reranking benefit.

\noindent\textbf{Scissors --- Feature Saturation.}
Scissors register zero success on both Stage~3 and Stage~4 (0/25 each),
a floor effect that prevents measuring reranking benefit or harm from task
outcomes alone.
We therefore diagnose the Scissors failure mode through score-level analysis
rather than net improvement.
Scissors have near-zero estimated height ($H_\mu \approx 0.001$\,m),
with 45.7\,\% of all candidates assigned $H < 0.001$.
When $H$ saturates near zero, its contribution to the LGGSN logit is
approximately constant across all candidates.
The model's output variance collapses (max--min score spread $< 0.002$ in
84\,\% of episodes) and selection effectively degrades to a function of
\texttt{dist\_to\_centroid} alone.
For Scissors, the XY centroid of top-down candidates corresponds to the
tip region---a geometrically poor grasping location.
The consistent regressions observed on PyBullet/Panda ($-4$), where Scissors
achieves non-zero baseline success (20/25), confirm that this score-collapse
mechanism causes task degradation when non-zero success is accessible.

\noindent\textbf{PowerDrill --- Orientation Ambiguity.}
The PowerDrill has the highest within-episode yaw spread
($\sigma_\psi = 0.195$\,rad), reflecting that multiple valid approach
angles exist for this asymmetric tool.
LGGSN uses world-frame yaw without object-frame normalisation, so the same
physical approach direction maps to different feature values depending on
how the drill is oriented in the scene.
The cross-episode training signal for PowerDrill is correspondingly noisy,
as ``good'' yaw values vary between episodes in a way the model cannot
learn from world-frame coordinates alone.

\noindent\textbf{CrackerBox and MustardBottle --- Consistent Gains.}
Both objects have clear height structure ($H > 0$,
$\sigma_{H,\text{w}} \approx 0.015$--$0.020$) and a consistent principal
grasping axis ($\sigma_\psi \approx 0.05$--$0.06$).
The \texttt{z\_rel} feature provides a reliable within-episode
discrimination signal: candidates at higher relative height correspond to
grasps on the upper body of the object rather than the table edge, and
this distinction is geometrically meaningful and consistent across
episodes.

\section{Discussion}
\label{sec:discussion}

\subsection{Offline vs.\ Online Transfer}

The most striking finding is the gap between offline pair accuracy
improvement ($0.447 \to 0.664$) and online task improvement (net $\approx 0$).
This gap has a structural explanation: offline pair accuracy measures
discrimination \emph{between} episodes from different scenes.
The context features are highly informative at this level.
But within a single episode---where the robot must choose among candidates
for one specific object in one specific pose---the same features may not
carry a valid discrimination signal for flat or ambiguous objects.
This exposes a general failure mode in grasp reranker evaluation: offline
pair accuracy is a necessary but not sufficient condition for online
improvement, and evaluations that report only offline accuracy risk
overstating expected task benefit.

\subsection{Cross-Platform Divergence}

The cross-platform results (\cref{tab:main,tab:main_pyb}) reveal qualitatively
opposite per-object patterns: CrackerBox is $-2$ on MuJoCo/SO-ARM101 but
$+4$ on PyBullet/Panda, while PowerDrill is $+4$ on MuJoCo but $-1$ on
PyBullet.
A plausible explanation involves contact-model fidelity (PyBullet simplified
rigid-body vs.\ MuJoCo soft-contact), candidate-set geometry (depth-map
characteristics differ between simulators), and kinematic reachability
(Panda vs.\ SO-ARM101).
MuJoCo/SO-ARM101 is the primary platform; PyBullet results serve as a
cross-platform sanity check.

\subsection{The Granularity Problem for Gating}

Both the $\sigma_H$ gate and the object-conditional whitelist attempt to
suppress reranking for problematic objects, yet each fails for a distinct
reason.
The $\sigma_H$ gate operates at episode granularity, but the failure mode
(flat\_frac) is a property of the object class, not a single episode.
The whitelist correctly models class-level failure but introduces a
comparison-baseline shift: blocking reranking for one condition changes
which Stage-3 scenes are sampled, making net improvement estimates
unreliable due to simulator non-determinism.

A principled solution would gate on the \emph{model's own uncertainty}: for
example, skipping reranking when the score spread across candidates is
below a threshold~$\delta$.
This approach is agnostic to failure mode (saturation vs.\ orientation
ambiguity) and does not require object-class labels at inference time.

\subsection{Difficulty Generalization on SO-ARM101}
A supplementary experiment varying spawn difficulty (easy/medium/hard,
50 seeds $\times$ 5 objects) found all three methods (geometry, random,
LGGSN) within noise of one another (65--72\,\%), confirming that pose
variation is the primary driver of difficulty and per-object geometry
determines sensitivity more than reranker choice.

\subsection{Statistical Power}
At $N = 25$ seeds, bootstrap 80\,\% CIs span $\pm 4$--$5$ trials; only
CrackerBox ($+4$) achieves $\geq 80\,\%$ power at this scale, so
per-object diagnoses are directionally supported but not conclusively
established.

% =============================================================================
\section{Conclusion}
\label{sec:conclusion}

LGGSN is a lightweight geometry-based grasp reranker trained with BPR loss
on live robot data and evaluated over 175 paired trials on a MuJoCo-simulated
SO-ARM101.
The central finding is that the net task improvement is near zero ($+1$):
a consistent PowerDrill gain ($+4$) is largely offset by regressions on
CrackerBox ($-2$), MustardBottle ($-1$), and Pear ($-1$).
Cross-platform validation on PyBullet/Panda (\cref{tab:main_pyb}) confirms
the same object-dependent pattern; the PyBullet Scissors regression ($-4$)
provides the starkest single-object contrast.
This behaviour persists across four system variants---ungated, flat-object
gated, class-conditional, and geometry-conditioned feature masking---all
achieving net $\approx 0$ at 25 seeds.

We identify two root causes predictable from geometric statistics:
feature saturation for flat/thin objects
(flat\_frac $\geq 0.4$ strongly correlated with regression in PyBullet
cross-platform analysis, $\rho = -0.96$)
and orientation ambiguity for asymmetric tools
($\sigma_\psi$ high, no object-frame encoding).
These diagnoses point to three requirements for a successor method:
\textit{(i)} object-frame-normalised orientation features or object-aware
pose canonicalisation (e.g., via VLM-predicted symmetry axes or superquadric
shape fitting~\cite{fang2023anygrasp});
\textit{(ii)} model-uncertainty-aware gating that disables reranking when
score spread falls below a meaningful threshold, for which conformal
prediction or Bayesian output variance provide principled score-spread estimates;
\textit{(iii)} explicit handling of degenerate-$H$ regimes for thin planar
objects, either by masking $H$ when below a calibrated floor or by
substituting a contact-normal–based feature that remains discriminative
for flat geometries.

More broadly, this work demonstrates that offline pair accuracy improvement
is necessary but insufficient for online task benefit, and provides a
replicable diagnostic framework for predicting per-object reranking
behaviour from geometric statistics alone.
All three identified requirements---object-frame orientation normalisation,
uncertainty-aware gating, and degenerate-$H$ handling---are technically
tractable, suggesting a clear path toward a geometry-based reranker that
generalises reliably across object classes.
