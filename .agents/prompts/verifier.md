# Independent verifier protocol

`verify.py` is an executable verifier, not an LLM role. It relies on actual artifacts:
exit codes, JSON validity, Git diff, protected-data manifests, and test output. It does
not rely on planner, executor, or reviewer natural-language claims.

`verifier.json` is generated by `verify.py`. A reviewer cannot modify its verdict. If
`verifier.json.verdict` is `FAIL`, the final workflow status cannot be `PASS`, even if
the reviewer returns `REVIEW_PASS`.
